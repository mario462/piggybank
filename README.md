# Piggy

A personal savings "piggy bank" split into categories, as an installable web app (PWA) for iPhone.
Add, withdraw and move money between categories (categories may go below zero), see the total and
allocation at a glance, drill into a category, and browse the full history. Works offline and syncs.

**Stack:** plain HTML/CSS/JS (no build step) · Cloudflare Pages + Pages Functions · Cloudflare D1 · Cloudflare Access.

## Layout

| Path | What |
|---|---|
| `public/` | The app: `index.html`, `css/`, `js/` (`ledger.js` math, `store.js` offline sync, `app.js` UI), service worker, icons, fonts, `_headers` |
| `functions/api/[[path]].js` | Routes `/api/*` to `server/api.js` |
| `server/` | API router, Access token verification, validation, D1 queries |
| `migrations/` | Reference schema (the API creates tables automatically) |
| `tests/unit/` | Ledger math, validation, and Access/API security tests (`node --test`) |
| `tests/e2e/` | Browser tests at iPhone 13 size against the real API with a local D1 (Playwright) |

## Develop

```sh
npm install
npm run dev        # http://localhost:8788 with a local D1; auth is bypassed on localhost only
npm test           # unit + browser tests
```

## Deploy

See [docs/cloudflare-setup.md](docs/cloudflare-setup.md). Every push to `main` deploys automatically.

## API

All routes need a valid Cloudflare Access session. Writes also need the header `X-Piggybank: 1`.
Amounts are integer cents. Ids are generated by the client so offline retries are safe.

| Method | Path | Body |
|---|---|---|
| GET | `/api/state` | — returns `{ categories, transactions }` |
| POST | `/api/transactions` | `{ id, type: add\|withdraw\|transfer, cat, to?, amount, note?, t? }` |
| DELETE | `/api/transactions/:id` | — |
| POST | `/api/categories` | `{ id, name, color, goal }` |
| PATCH | `/api/categories/:id` | any of `{ name, color, goal }` |
| DELETE | `/api/categories/:id` | — (only when it has no transactions) |
